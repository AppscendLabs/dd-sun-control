# D & D Sun Control — Website

This is the source code for the D & D Sun Control website (danddsuncontrol.com), built with [Next.js](https://nextjs.org).

**New to this project?** Start with the guides in [`docs/`](./docs):

| Guide | Who it's for |
|---|---|
| [`docs/01-overview-for-owners.md`](./docs/01-overview-for-owners.md) | Non-technical owners — what this site is, what you can safely touch, who to call |
| [`docs/02-project-structure.md`](./docs/02-project-structure.md) | Anyone making code changes — map of every folder/file and what it controls |
| [`docs/03-deployment-vercel.md`](./docs/03-deployment-vercel.md) | How the site goes live, Vercel setup, environment variables, rollbacks |
| [`docs/04-ownership-transfer-guide.md`](./docs/04-ownership-transfer-guide.md) | Appscend Labs — how to hand off GitHub + Vercel correctly |

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the site. Changes to files under `src/` hot-reload automatically.
